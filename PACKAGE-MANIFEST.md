## Fun-first build gates

- Phase 1 ends with eight distinct starting definitions, 12–16 instances, three patterns, four base/five expanded valid stacks and a ten-person playtest worksheet.
- Phase 1 includes Teased → Discovered → Expanded Handbook states, free invalid experimentation and one Staff-studied Tactic rule expansion.
- Phase 2 is limited to 30 playable housing definitions, 16 patterns, four Tactic effects, at least 50 concrete stacks and 12 Story Director events.
- Expansion to 77 definitions, 38 patterns, 20 Tactic effects, at least 200 concrete stacks and production art begins only after Checkpoint 2 approval.
- Real lawmakers use portrait-free member-office treatments throughout the vertical slice.
- The complete term reveals seeded opponent strength in Week 1, labels the election outlook simulated/not polling and resolves reelection through a visible ledger with no final random draw or demographic input.

## External prerequisites not bundled

- Claude Code
- Node.js 20+
- npm
- Git
- A modern browser
- `superpowers:executing-plans` for the exact checkpoint workflow
- Optional Phaser Game Agent MCP account, connection and credits

No credentials, API keys, government datasets, third-party icon files, lawmaker photographs or generated production card art are included. The bundled Civic Illustration Kit is project-authored prototype source artwork. The vertical-slice plan deliberately excludes lawmaker photographs; other assets enter the project only through the sourcing and validation processes defined in the specifications and plan.
